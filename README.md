# Timer & Stopwatch

A sleek, Vercel-inspired Timer and Stopwatch built with React and TypeScript.

## Features

- **Timer & Stopwatch Modes:** Easily toggle between counting down and counting up.
- **Custom Wheel Picker:** Native-feeling, iOS-style dial pickers built entirely with CSS \`scroll-snap\` and React state.
- **Smooth Animations:** Numbers seamlessly lock into place using native smooth scrolling behaviors.
- **Minimalist UI:** A high-contrast, clean dark theme inspired by modern developer tools.

## Tech Stack

- **React 18** (Hooks: \`useState\`, \`useEffect\`, \`useRef\`, \`useCallback\`)
- **TypeScript**
- **Vite**
- **Vanilla CSS** (Scroll Snapping, Flexbox)
